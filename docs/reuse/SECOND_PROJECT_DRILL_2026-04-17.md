# 第二项目接入演练（2026-04-17）

## 目标

验证 `templates/project-starter` 是否足以支撑第二个项目从零起盘。

本次演练项目名：

- `SupportForge`

## 演练步骤

1. 复制模板目录
2. 替换项目名与业务域
3. 填写项目 brief
4. 保留统一的 agent 权限边界
5. 产出第一批原子任务样板

## 预期结论

- 模板可直接复用
- 只需替换业务域，不需要重写控制平面规则
- 任务 contract、bootstrap prompt、agent 边界可以跨项目保留

## 复用时应替换的内容

- 项目名称
- 业务目标
- 目标模块
- 外部系统清单
- 验收命令

## 复用时不应替换的内容

- 原子任务 contract 思路
- `read_set / write_set` 边界
- 验收必须证据驱动
- 知识写入必须后置于验收

## 验收标准

- 新项目能在不依赖聊天历史的前提下启动
- 新线程能按 bootstrap prompt 建立上下文
- 原子任务样板可以直接改造成业务任务
